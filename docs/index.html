⚠️ PROOF OF CONCEPT — NOT CLINICALLY TESTED

This tool has not been tested clinically and is a proof-of-concept for research and software demonstration only. It is not a medical device, it does not diagnose, treat, or rule out any condition, and its outputs may be wrong — including false positives and false negatives.

Do not use it to make decisions about your health. For any medical issue or concern, seek a licensed healthcare professional. In an emergency, go to your nearest emergency room or dial 911 immediately.

DEMO DATA

Pose-Not-Pixels

TUG trend and knee/hip arthritis kinematics from skeleton landmarks only. Video never reaches a model.

Static GitHub Pages preview. No backend and no AI model are connected — everything below runs in your browser on pretend data and shows sample outputs only. The real tool is open source and self-hostable: github.com/rtmalikian/pose-not-pixels

Try the mini-demo

The real tool turns video into 33 skeleton landmarks on-device, then does deterministic maths in code — the model only phrases ~100 tokens of metrics JSON. Try sample metrics:



Screening information for clinician review only. The 12s TUG point is a CDC STEADI screening flag ("discuss with a clinician"), not a risk label; all other thresholds are app-defined and unvalidated. Sensitivity/specificity are unknown until clinical validation.




Run the real thing (self-hosted)


Clone the repo and start it with Docker Compose — it ships with an embedded OpenAI-compatible gateway (stub / local model / any OpenAI-compatible upstream), so PHI never has to leave your machine:
git clone https://github.com/rtmalikian/pose-not-pixels
cd pose-not-pixels
docker compose up
